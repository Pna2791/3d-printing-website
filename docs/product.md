# Product Overview

## Problem
3D printing workshops lack a unified digital platform to:
- Show real-time printer availability
- Provide transparent pricing
- Automate STL-based quoting

## Target Users
- Customers needing 3D printing services
- Workshop operators managing machines and materials

## Core Features
1. Real-time printer availability dashboard
2. Material pricing display
3. STL file upload & automatic price estimation
4. Admin dashboard for managing printers & materials

## User Flow
1. User visits website
2. Views available printers
3. Checks material pricing
4. Uploads STL → gets instant quote
5. Places order
